# 3_Projects — Working Projects

Non-build work that outlives a session: research, standard operating procedures, recurring analyses,
anything that stays in markdown rather than becoming a tool.

Empty until you need it. One folder per project.

## What belongs here

- A recurring analysis you now run monthly, with its method written down
- Research that informs a decision but isn't itself a deliverable
- An SOP you wrote from something you figured out in these sessions
- A running log on a problem you're working over several months

## What doesn't

- **Things you build** — dashboards, calculators, apps. Those go in `4_Build_Projects/`
- **Session outputs** — those go in `2_Outputs/.agents/`
- **Data** — that's `5_Library/sources/`
- **Facts about your organization** — that's `0_Org/`, via `util_get_org_info`

## Naming

`YYYY.MM Short Name` — e.g. `2026.09 Support Cost Model Review`. Dated folders sort chronologically
and tell you at a glance what's stale.
