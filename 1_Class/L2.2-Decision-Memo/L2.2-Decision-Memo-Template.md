## The four tests

<!-- Run these before you send it. Check each. -->

- [ ] **Ninety-second test** — read only the recommendation paragraph. Could they act correctly?
- [ ] **Skeptic test** — the reader's sharpest colleague. What's their first question? Is it answered?
- [ ] **Forward test** — six months on, it went badly and someone pulls this up. Does it hold? Did it name the risk that materialized?
- [ ] **Hostile-quote test** — which sentence would someone pull out of context to misrepresent this? Rewrite it.
