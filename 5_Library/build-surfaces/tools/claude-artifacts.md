# Claude Artifacts

Interactive pages Claude builds and hosts, shareable as a link. Charts, calculators, dashboards,
forms.

**What it's for here:** a scenario calculator with sliders on the assumptions, a dashboard for a
single meeting, anything where letting someone move an input makes the argument better than
describing it would.

**Cost:** included with Claude.

**Quickstart**

1. In Claude, describe what you want and attach or paste the data
2. Ask for it as an interactive page
3. Iterate — "put the range next to the headline number", "sort the bars by value", "label the lines
   directly instead of using a legend"
4. Publish and share the link

**The tradeoff:** it's a snapshot. Refreshing with new data means rebuilding it. Ideal for a one-time
answer, wrong for a monthly report.

**Make sure the uncertainty survives.** Sliders that produce a single confident number are worse than
a spreadsheet, because interactivity reads as rigor. The range has to be on screen next to the
answer.
