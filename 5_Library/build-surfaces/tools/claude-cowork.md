# Claude Cowork

A shared workspace — multiple people, shared files, shared context with Claude.

**What it's for here:** when the analysis is a team effort, when a colleague picks up where you left
off, or when the output is a living document rather than a one-time artifact.

**Cost:** included with eligible Claude plans.

**Quickstart**

1. Create a workspace for the project
2. Add the files everyone needs — the data, the decision frame, the analysis
3. Work in it with Claude alongside your colleagues
4. Keep the shared context current. That's what makes it better than everyone prompting separately
   from their own chat history

**Where it fits with this repo:** this workspace is designed for one person and their files. Cowork
is the natural next step when the work outgrows that — a team maintaining a shared set of metric
definitions and recurring analyses together.

**Confidentiality note:** a shared workspace means shared visibility. Check who's in it before you
add anything sensitive, and remember that "shared with the team" and "shared with the company" are
different settings.
